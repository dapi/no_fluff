Представляет из себя :

# Телеграм бота @no_fluff_bot

Этот бот принимает от пользователя набор телеграм каналов, которые пользователю
интересны. Следит за ними, и выдает пользователю ТОЛЬКО важную информацию из
каналов. Без рекламы. Без шелухи.

Пользователь может выбрать:

1. как часто он хочет получать сообщения из каналов (несколько раз в день, в неделю)
2. получать сообщения из каналов по одному, группой или выжимку.
3. пользователь имеет возможность посмотреть за какими каналами еще смотрят
   другие пользователи, которые наблюдают за его каналами.
4. Пользователь имеет возможност проголосовать за материал (понравился/не
   понравился) и таким образом нейронка лучше поймет какие материалы ему
   подходят.

Таким образом:

1. Пользователь получает контент без шелухи.
2. Создается социальная сеть через которую продвигаются интересные каналы на
   схожую тематику.

# Канал t.me/no_fluff

Куда попадают лучшие материалы из всех подписок за неделю. Каждый день.
