## Ручная валидация спецификаций

Хотя автоматическая проверка отключена, вы можете вручную проверить качество спецификаций:

### Быстрые команды
```bash
# Валидация всех спецификаций
./bin/rake specs:validate_all

# Валидация конкретной спецификации
./bin/rake "specs:validate[054]"

# Комплексная проверка статусов
./docs/.spec_status_check.sh
```

### Когда использовать ручную проверку
- Перед созданием Pull Request
- Перед важными коммитами
- При обновлении документации
- Перед релизом

## Преимущества изменений

1. **Коммиты не блокируются** из-за черновиков спецификаций
2. **Гибкость в разработке** - можно коммитить незавершенную документацию
3. **Сохранение контроля качества** через ручные проверки
4. **Ускорение процесса разработки**

## Рекомендации по использованию

1. **Разработка**: Коммитьте черновики без опасений
2. **Code Review**: Запускайте валидацию перед PR
3. **Релиз**: Проверяйте все спецификации перед релизом
4. **Командная работа**: Используйте `docs/.spec_status_check.sh` для обзора статусов

## Формула работы
```
Разработка → Коммит с черновиками → Ручная валидация → Code Review → Merge
```

Это позволяет быстро разрабатывать документацию, сохраняя при этом контроль качества на ключевых этапах.
