# Функциональные возможности бота "Без шелухи"

## Основная цель продукта

**Создать продукт, который позволяет полностью избавиться от информационного шума** - получать только ценный контент без рекламы, "воды" и второстепенной информации из Telegram-каналов, экономя время и нервы пользователей.

## Основные фичи

1. **Гибкая настройка частоты доставки**
   Пользователь может выбрать, как часто он хочет получать сообщения из каналов: несколько раз в день, раз в день, несколько раз в неделю или раз в неделю.

2. **Разные форматы доставки контента**
   Пользователь может получать сообщения из каналов по одному, группой или в виде выжимки (краткого саммари).

3. **Социальная сеть каналов**
   Пользователь имеет возможность посмотреть, за какими каналами еще смотрят другие пользователи, которые наблюдают за его каналами. Это помогает открывать новые интересные источники информации.

4. **Обучаемая система фильтрации**
   Пользователь может проголосовать за материал (понравился/не понравился), и таким образом нейронная сеть лучше поймет, какие материалы ему подходят.

5. **Автоматическое удаление дубликатов**
   Бот автоматически удаляет дубликаты новостей из разных каналов, даже если они по-разному сформулированы. Каждая новость доставляется только один раз.

6. **Приоритизация каналов**
   Пользователь может установить приоритет для каждого канала, чтобы получать материалы из важных источников в первую очередь.

7. **Тематическая фильтрация**
   Возможность настроить фильтры по ключевым словам и темам, чтобы получать только релевантный контент из широкотематических каналов.

8. **Статистика и аналитика**
   Пользователь может просматривать статистику: сколько контента было отфильтровано, какие темы наиболее интересны, активность по каналам.

## Служебные follower-аккаунты

- `Кеша Васильев` — вымышленный персонаж, а не реальный пользователь, клиент или автор отзыва.
- Связанный Telegram-профиль предназначен для подписки на каналы и получения публикаций в контуре No Fluff / «Без шелухи».
- Канонический паспорт телефонной линии и её связь с семейным контактным каталогом принадлежат `repo://dapi/personal/telecom/lines/79951041075.md`; этот документ владеет только проектным назначением персонажа.
- В аналитике и интерфейсах служебный follower-аккаунт нужно отделять от пользовательских аккаунтов и не учитывать как органический рост продукта.

## 🚀 Будущие возможности (в ROADMAP)

9. **Расширение на группы и чаты**
   В следующих версиях бот сможет отслеживать и фильтровать контент не только из каналов, но и из групповых чатов, что обеспечит полный контроль над информационным потоком в Telegram.

10. **Умная фильтрация групповых дискуссий**
   AI будет анализировать сообщения в группах, определять наиболее важные обсуждения и фильтровать оффтопные сообщения и флуд.
