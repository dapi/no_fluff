# User Flow: Онбординг bez_sheluhi_bot

## 🎬 Шаг 1: Первое сообщение (/start)

```
👋 Привет! Я бот Без Шелухи.

Устал от информационного шума в Telegram?
Я помогу тебе полностью от него избавиться!

Следи за каналами без рекламы, шелухи и мусора.
Получай только то, что действительно важно.

📊 Возвращай себе 40+ минут в день!

Начнём?

[Кнопка: 🚀 Давай начнём]  [Кнопка: ℹ️ Подробнее]
```

---

## 📝 Шаг 2: Добавление каналов

**Если нажал "Давай начнём":**

```
Отлично!

📢 Пришли мне ссылки на Telegram-каналы, за которыми я буду следить.

Можешь отправить:
• Ссылку: t.me/channelname
• Пересланное сообщение из канала
• Несколько каналов сразу (каждый с новой строки)

Например:
t.me/habr_com
t.me/dev_channel
t.me/tech_news

💡 Рекомендую начать с 5-10 каналов.

[Кнопка: 📋 Мои подписки] (для выбора из списка подписок пользователя)
```

**После отправки первого канала:**
```
✅ @channelname добавлен!

Отправь ещё каналы или нажми "Готово".

Добавлено каналов: 1

[Кнопка: ✔️ Готово, настроим бота]
```

---

## ⚙️ Шаг 3: Быстрая настройка (2 ключевых вопроса)

### Вопрос 1: Частота

```
Отлично! Добавлено 7 каналов.

⏰ Как часто присылать тебе дайджесты?

[Кнопка: 🌅 Раз в день утром] ⭐ популярно
[Кнопка: 🌅🌆 Два раза (утро/вечер)]
[Кнопка: ⚡ В реальном времени]
[Кнопка: 📅 Раз в неделю]
[Кнопка: ⚙️ Настроить точно]
```

### Вопрос 2: Формат

```
Супер! Буду присылать раз в день в 09:00.

📋 В каком формате показывать контент?

[Кнопка: 🎯 Топ-3 + краткие саммари] ⭐ рекомендую
[Кнопка: 📰 Полные тексты важных постов]
[Кнопка: 📝 Единый дайджест на 5 минут]
[Кнопка: ⚡ Только заголовки]

💡 Можешь изменить в любой момент через /settings
```

## 🎉 Шаг 4: Подтверждение и первое действие

```
🎉 Всё готово!

Настройки:
📢 Каналов: 7
⏰ Частота: каждый день в 09:00
📋 Формат: топ-3 + саммари
🎯 Фильтрация: высокая (важное)

Я уже начал следить за твоими каналами!

Завтра в 09:00 получишь первый дайджест.

Но если не хочешь ждать...

[Кнопка: ⚡ Покажи что сейчас важного!]
```

**Если нажал "Покажи что сейчас важного":**

```
⏳ Анализирую последние 24 часа из 7 каналов...

[Через 3-5 секунд]

📊 Нашёл 3 важных материала из 47 постов:

[Показывает первый дайджест в выбранном формате]

---

💡 Полезные команды:
👍 /like или 👎 /dislike — оцени материал
⚙️ /settings — изменить настройки
➕ /add — добавить каналы
📊 /stats — статистика

Вопросы? Напиши /help
```

**Если на шаге 1 нажал "Подробнее":**

```

1️⃣ Ты добавляешь свои Telegram-каналы
2️⃣ Я читаю все посты и фильтрую важное с помощью AI

✨ Что я умею:
• 🚫 **Полностью убираю информационный шум** - рекламу, шелуху, мусор

• 🔍 Рекомендую качественные каналы без шума

🆓 Бесплатно: до 10 каналов
💎 Premium: безлимит каналов + приоритет + аналитика

[Кнопка: 🚀 Начать использовать]
```

## 🎯 Дополнительные элементы онбординга

### После первого дайджеста (на следующий день):

```
👋 Привет! Как тебе первый дайджест?

Помоги мне улучшиться:
👍 Ставь /like на полезные материалы
👎 Ставь /dislike на неинтересные

Так я пойму твои предпочтения и буду подбирать контент точнее.

[Кнопка: ✅ Понятно]  [Кнопка: ❌ Не показывать подсказки]
```

### После 3-го дайджеста (через 3 дня):

```
📊 Короткая статистика:

За 3 дня:
• Прочитал за тебя: 142 поста
• Отправил важных: 9 материалов
• Отфильтровал рекламы: 23 поста
• Сэкономил времени: ~87 минут

💡 Знаешь, что можешь:
• Добавить больше каналов: /add
• Изменить частоту: /settings
• Посмотреть рекомендации: /discover

[Кнопка: 🎁 Порекомендовать другу]
```

## ⚡ Быстрые команды (всегда доступны)

```
/start — начать заново
/add — добавить каналы
/list — мои каналы
/settings — настройки
/digest — показать дайджест сейчас
/stats — статистика
/discover — рекомендации каналов
/help — помощь
```

---

## 🎨 Принципы дизайна онбординга

1. **Минимум трения** - 2 вопроса вместо 10
2. **Быстрый результат** - можно получить первый дайджест сразу
3. **Прогрессивное раскрытие** - сначала главное, детали потом
4. **Обучение на ходу** - подсказки приходят когда актуальны
5. **Дефолты для ленивых** - можно просто жать "Далее"
6. **Визуальная структура** - эмоджи, кнопки, короткие блоки

---

## 🎯 Критичные метрики онбординга

- **Завершили онбординг:** >70%
- **Добавили хотя бы 3 канала:** >80%
- **Вернулись на 2-й день:** >50%
- **Активны через неделю:** >40%
