# Спецификация исправления команды /list

## Описание проблемы

По команде /list выводится список подписанных каналов с inline-кнопками управления. Текущие проблемы:

1. **Несоответствие списка и кнопок** - кнопки управления не соответствуют порядку каналов в списке
2. **Лишние кнопки** - кнопки "вверх" (⬆️) и "вниз" (⬇️) для изменения приоритета бесполезны для обычных пользователей
3. **Путаница в UX** - пользователь ожидает видеть только кнопку удаления для каждого канала

## Требования к исправлению

### Функциональные требования

1. **Удалить кнопки изменения приоритета** (⬆️ и ⬇️) из списка каналов
2. **Оставить только кнопку удаления** (🗑️) для каждого канала
3. **Сохранить порядок отображения** каналов по приоритету (от высокого к низкому)
4. **Упростить UX** - сделать интерфейс чистым и понятным

### Нефункциональные требования

1. **Сохранить обратную совместимость** - команда /list должна работать как раньше
2. **Сохранить функциональность удаления** - пользователь должен мочь удалять каналы
3. **Обновить тексты локализации** если необходимо
4. **Сохранить пагинацию** если список большой (текущая реализация)

## Ожидаемый результат

После исправления команда /list будет показывать:

```
📋 Мои подписки

Всего каналов: 3

• Канал 1 (приоритет: 10)
• Канал 2 (приоритет: 5)
• Канал 3 (приоритет: 1)

[🗑️] [🗑️] [🗑️]
```

Где каждая кнопка 🗑️ соответствует каналу в том же порядке.

## Критерии приемки

1. ✅ Команда /list показывает список каналов без кнопок вверх/вниз
2. ✅ Каждая кнопка 🗑️ удаляет соответствующий канал
3. ✅ Порядок каналов соответствует приоритету (высокий → низкий)
4. ✅ Сохраняется функциональность удаления и подтверждения
5. ✅ Нет ошибок в логах при использовании команды
6. ✅ Тесты проходят успешно
