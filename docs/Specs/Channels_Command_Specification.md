# Спецификация команды /channels

## Обзор

Команда `/channels` предназначена для отображения списка всех каналов в системе с информацией о количестве подписчиков для каждого канала. Команда доступна только администраторам системы.

## Функциональные требования

### 1. Авторизация
- Команда должна быть доступна только пользователям с правами администратора (`is_admin: true`)
- При попытке выполнения обычным пользователем должно отображаться сообщение об отсутствии прав доступа

### 2. Отображение информации
- Команда должна выводить список всех каналов в системе
- Для каждого канала должна отображаться следующая информация:
  - Название канала (если доступно) или username в формате @channelname
  - Количество активных подписчиков
  - Статус канала (активен/неактивен)
  - Дата последнего поста (если есть)
  - Иконка верификации (если канал верифицирован)

### 3. Формат вывода
- Информация должна быть представлена в виде отформатированного сообщения
- Каналы должны быть отсортированы по количеству подписчиков (по убыванию)
- Использовать эмодзи для визуального представления статусов

## Нефункциональные требования

### 1. Производительность
- Запрос должен выполняться не дольше 2 секунд

### 2. Безопасность
- Проверка прав администратора должна выполняться до выполнения основного кода
- Все операции должны логироваться для аудита

### 3. UX/UI
- Дружелюбные сообщения об ошибках
- Информативные заголовки для каждого раздела
- Использование локализации для всех текстов

## Текстовые сообщения

### Сообщение об отсутствии прав доступа
```
⛔️ У вас нет прав для выполнения этой команды.
Доступ к команде /channels имеют только администраторы системы.
```

### Заголовок списка каналов
```
📊 Список каналов системы

Всего каналов: {total_count}
Активных каналов: {active_count}
```

### Формат строки одного канала
```
{verification_icon} @{username} - {subscribers_count} подписчиков
{status_icon} {status_text} • {last_post_info}
```

### Иконки и статусы
- Верификация: ✅ (верифицирован), ⭕ (не верифицирован)
- Статус: 🟢 (активен), 🔴 (неактивен)
- Последний пост: "Последний пост: {time_ago}" или "Постов пока не было"

### Сообщение при отсутствии каналов
```
📭 В системе пока нет ни одного канала.

Используйте команду /add для добавления первого канала.
```

## Техническая реализация

### 1. Контроллер
- Создать метод `channels!` в `TelegramWebhookController`
- Добавить проверку прав администратора
- Использовать сервис для обработки бизнес-логики

### 2. Сервис
- Создать `Telegram::ChannelsListService`
- Методы:
  - `execute(current_user)` - основной метод
  - `build_channels_list()` - построение списка каналов

### 4. Логирование
- Логировать выполнение команды администратором
- Логировать время выполнения запроса
- Логировать ошибки (если есть)

## Обработка ошибок

### 1. Отсутствие прав доступа
- Статус: 403 Forbidden
- Логирование: "Пользователь {username} попытался выполнить команду /channels без прав администратора"

### 2. Ошибка базы данных
- Статус: 500 Internal Server Error
- Сообщение пользователю: "Произошла ошибка при получении списка каналов. Попробуйте позже."
- Логирование: полной ошибки в Bugsnag

### 3. Таймаут запроса
- Статус: 504 Gateway Timeout
- Сообщение пользователю: "Запрос выполняется слишком долго. Попробуйте позже."
