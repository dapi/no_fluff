# Спецификация команды /channels

## Обзор
Команда `/channels` предназначена для отображения списка всех каналов в системе с информацией о количестве подписчиков. Доступна только администраторам.

## Требования

### Функциональные требования
1. **Проверка прав доступа**: Команда должна быть доступна только пользователям с флагом `is_admin: true`
2. **Отображение списка**: Показывать все каналы в системе
3. **Информация о подписчиках**: Для каждого канала отображать количество активных подписчиков
4. **Сортировка**: Каналы должны быть отсортированы по количеству подписчиков (убывание)
5. **Статус канала**: Отображать статус канала (активный/неактивный)
6. **Пагинация**: Если каналов много, выводить с пагинацией (по 20 каналов на странице)

### Нефункциональные требования
1. **Безопасность**: Проверка административных прав перед выполнением
2. **Производительность**: Запрос должен быть оптимизирован для работы с большим количеством каналов
3. **Удобство использования**: Понятный формат вывода с возможностью навигации

## Формат вывода

### Основной формат
```
📊 Список каналов в системе (всего: {total_count})

1. @channel_name - 📊 {subscribers_count} подписчиков ✅
   📝 Описание: {description}
   📅 Последний пост: {last_post_at}

2. @channel_name2 - 📊 {subscribers_count} подписчиков ❌
   📝 Описание: {description}
   📅 Последний пост: {last_post_at}
```

### Индикаторы статуса
- ✅ Активный канал
- ❌ Неактивный канал
- ⚠️ Канал не обновлялся долго (>7 дней)

### Пагинация
- Показывать по 20 каналов на странице
- Кнопки навигации: "← Предыдущая", "Следующая →"
- Отображение текущей страницы: "Страница {current} из {total}"

## Проверка прав доступа
1. Проверить `current_user.is_admin?`
2. Если не администратор - показать сообщение об отказе в доступе
3. Логировать попытку несанкционированного доступа

## Обработка ошибок
1. **Нет прав доступа**: Показать сообщение `🚫 У вас нет прав для выполнения этой команды.`
2. **Нет каналов в системе**: Показать сообщение `📭 В системе пока нет каналов.`
3. **Ошибка базы данных**: Показать общее сообщение об ошибке и логировать детали

## Оптимизация запросов
1. Использовать `includes(:subscriptions)` для предзагрузки подписок
2. Считать подписчиков через `COUNT` с фильтром `active: true`
3. Добавить индексы для оптимизации запросов

## Расширения (будущие версии)
1. **Фильтрация**: По статусу, количеству подписчиков, дате последнего поста
2. **Поиск**: По названию или описанию канала
3. **Действия с каналами**: Активация/деактивация, удаление
4. **Статистика**: График роста подписчиков, активность каналов
5. **Экспорт**: Выгрузка списка в CSV/Excel

## Тестирование
1. **Позитивные сценарии**:
   - Администратор видит список каналов
   - Корректный подсчет подписчиков
   - Правильная сортировка
   - Пагинация работает корректно

2. **Негативные сценарии**:
   - Не-администратор не может выполнить команду
   - Обработка пустого списка каналов
   - Обработка ошибок базы данных
