# Спецификация: Сохранение времени удачного обновления канала (fetchpostjob)

## Обзор

Функциональность для отслеживания и сохранения времени последнего успешного обновления канала после выполнения фоновой задачи fetchpostjob.

## Проблема

В настоящее время отсутствует механизм для отслеживания времени успешного обновления каналов, что затрудняет мониторинг работы системы и определение актуальности данных.

## Цель

Реализовать сохранение временной метки последнего успешного обновления для каждого канала, что позволит:
- Отслеживать актуальность данных каналов
- Определять проблемные каналы с долгим временем без обновления
- Предоставлять статистику по обновлениям

## Требования

### Функциональные требования

1. **Сохранение временной метки**
   - После успешного выполнения задачи fetchpostjob для канала
   - Сохранять точное время завершения обновления
   - Обновлять только при успешном выполнении

2. **Хранение данных**
   - Добавить поле в модель Channel для хранения времени последнего обновления
   - Использовать тип timestamp with time zone для точности
   - Поле должно быть nullable для каналов без обновлений

3. **Отображение информации**
   - Показывать время последнего обновления в интерфейсе
   - Отображать время в локальном формате пользователя
   - Добавить индикатор "давно не обновлялся" для старых каналов

### Нефункциональные требования

1. **Производительность**
   - Минимальное влияние на время выполнения основной задачи
   - Индекс по полю времени обновления для быстрых запросов

2. **Надежность**
   - Сохранение времени только после успешного завершения всех операций
   - Обработка ошибок при сохранении временной метки

3. **Совместимость**
   - Обратная совместимость с существующими каналами
   - Не прерывать работу существующих процессов

## Модель данных

### Изменения в модели Channel

```ruby
# Добавляем поле
t.timestamp :last_successful_update_at, null: true
```

### Индексы

```ruby
# Индекс для запросов по времени обновления
add_index :channels, :last_successful_update_at
```

## API

### Методы модели Channel

```ruby
# Обновление времени успешного обновления
def mark_as_successfully_updated
  update!(last_successful_update_at: Time.current)
end

# Проверка на актуальность канала
def stale?(threshold = 24.hours)
  last_successful_update_at.blank? ||
  last_successful_update_at < threshold.ago
end

# Форматированное время обновления
def last_update_formatted
  return I18n.t('channels.never_updated') if last_successful_update_at.blank?

  I18n.l(last_successful_update_at, format: :short)
end
```

## Интеграция с существующим кодом

### Модификация Jobs::FetchPostJob

1. После успешного выполнения всех операций с каналом
2. Вызвать метод `channel.mark_as_successfully_updated`
3. Обернуть в rescue чтобы не прерывать основную логику

## Локализация

Добавить переводы в `config/locales/ru.yml`:

```yaml
ru:
  channels:
    never_updated: 'Никогда не обновлялся'
    last_update: 'Последнее обновление'
    status:
      fresh: 'Актуальный'
      stale: 'Устаревший'
```
