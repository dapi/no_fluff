# Спецификация: Простое деление подписками (Simple Subscription Sharing)

## Обзор
Простой функционал для пользователей, позволяющий делиться своими подписками на Telegram-каналы с другими пользователями бота.

## Цель
Позволить пользователям легко обмениваться интересными каналами, повышая вовлеченность и социальную ценность бота.

## Основные сценарии использования

### 1. Отправка подписок другу
**Действие:** Пользователь А хочет поделиться своими подписками с Пользователем Б

**Flow:**
1. Пользователь А вызывает команду `/share`
2. Бот показывает список подписок пользователя А с возможностью выбора
3. Пользователь А выбирает каналы для поделиться
4. Бот генерирует уникальную ссылку-приглашение
5. Пользователь А отправляет эту ссылку Пользователю Б
6. Пользователь Б переходит по ссылке и подписывается на каналы

### 2. Получение подписок
**Действие:** Пользователь Б получает ссылку на подписки

**Flow:**
1. Пользователь Б переходит по ссылке вида `https://t.me/nofluff_bot?start=share_abc123`
2. Бот распознает share-код и показывает список каналов
3. Пользователь Б выбирает интересующие каналы
4. Бот добавляет выбранные каналы в подписки пользователя Б

## Модели данных

### ShareLink (новая модель)
```ruby
class ShareLink < ApplicationRecord
  belongs_to :telegram_user

  validates :token, presence: true, uniqueness: true
  validates :expires_at, presence: true

  scope :active, -> { where('expires_at > ?', Time.current) }
  scope :by_user, ->(user) { where(telegram_user: user) }

  def expired?
    expires_at < Time.current
  end
end
```

### SharedChannel (новая модель)
```ruby
class SharedChannel < ApplicationRecord
  belongs_to :share_link
  belongs_to :channel
  belongs_to :telegram_user

  validates :share_link_id, uniqueness: { scope: :channel_id }
end
```

## Business правила

### Ограничения
1. Количество каналов в одной ссылке: не более 20
2. Срок действия ссылки: 7 дней
3. Максимум использований одной ссылки: 10 раз
4. Максимум активных ссылок на пользователя: 3

### Безопасность
1. Ссылки содержат уникальный токен
2. Автоматическое истечение срока действия
3. Проверка на спам (ограничение создания ссылок)

## Требования к реализации

### Backend
1. Модели ShareLink и SharedChannel
2. Сервис ShareLinkService для управления ссылками
3. Валидация и бизнес-логика
4. Background job для очистки истекших ссылок

### Bot Interface
1. Обработчик команды /share
2. Обработчик /start с share-параметром
3. Inline клавиатуры для выбора каналов
4. Формирование сообщений со ссылками

### Database
1. Таблица share_links
2. Таблица shared_channels
3. Индексы для производительности

## Метрики успеха
- Количество созданных ссылок: 500+/месяц
- Конверсия в подписки: 30%+
- Среднее количество каналов на одну ссылку: 5-8
- Вовлеченность новых пользователей через ссылки: 15%+

## KPI
1. **Viral Coefficient** - сколько новых пользователей приводит один существующий
2. **Share Rate** - процент пользователей, делящихся подписками
3. **Conversion Rate** - процент переходов по ссылкам в подписки

## Ограничения версии
- Только текстовые каналы (не обрабатываем медиа-каналы)
- Без персонализированных рекомендаций
- Без аналитики по использованию ссылок
