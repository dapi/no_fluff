# Спецификация: Установка команд бота через API

## Название функциональности

**Telegram Bot Commands Management** - Система автоматического определения и установки команд бота через Telegram Bot API

## Обзор

Функциональность позволяет автоматически определять все доступные команды бота из исходного кода и устанавливать их через Telegram Bot API методом `setMyCommands`. Это обеспечивает актуальность меню команд в интерфейсе Telegram.

## Требования

### Функциональные требования

1. **Автоматическое определение команд**
   - Сканирование `TelegramWebhookController` и всех включаемых `concerns`
   - Извлечение методов команд (методы с `!` в конце)
   - Определение описаний команд из локализации

2. **Установка команд через API**
   - Использование метода `setMyCommands` Telegram Bot API
   - Обработка ошибок при установке
   - Логирование результатов операции

3. **Управление командами**
   - Rake задача для установки команд
   - Административная команда `/set_commands`
   - Возможность просмотра текущих команд

4. **Локализация**
   - Поддержка описаний команд на русском языке
   - Использование существующей системы `I18n.t`

### Нефункциональные требования

1. **Надежность**
   - Обработка ошибок API
   - Валидация формата команд
   - Graceful degradation при недоступности API

2. **Производительность**
   - Кеширование списка команд
   - Минимальная задержка при установке

3. **Совместимость**
   - Работа с существующей архитектурой
   - Поддержка тестовой среды

## Архитектура

### Компоненты

1. **`Telegram::CommandsManager` (сервис)**
   - Основной класс для управления командами
   - Автоматическое определение команд из кода
   - Взаимодействие с Telegram API

2. **`Telegram::CommandsScanner` (сервис)**
   - Сканирование контроллеров и concerns
   - Извлечение метаданных команд

3. **Rake задача `telegram:set_commands`**
   - Консольная утилита для установки команд

4. **Административная команда `/set_commands`**
   - Команда для управления из чата

### Процесс работы

1. **Сканирование кода**
   - Поиск всех методов с `!` в `TelegramWebhookController`
   - Анализ включенных `concerns`
   - Сбор метаданных команд

2. **Формирование списка команд**
   - Создание массива объектов `BotCommand`
   - Добавление описаний из локализации
   - Валидация формата

3. **Установка через API**
   - Вызов `bot.set_my_commands(commands: commands)`
   - Обработка ответа API
   - Логирование результатов

## Структура данных

### BotCommand объект

```ruby
{
  command: 'start',        # String - имя команды (без /)
  description: 'Начать работу с ботом'  # String - описание команды
}
```

### Локализация

```yaml
# config/locales/ru.yml
ru:
  telegram_bot:
    commands:
      start: 'Начать работу с ботом'
      help: 'Показать справку'
      settings: 'Настройки бота'
      # ... другие команды
```

## API

### Основные методы

```ruby
# Получение списка всех команд
Telegram::CommandsManager.new.all_commands
# => [{ command: 'start', description: '...' }, ...]

# Установка команд в Telegram
Telegram::CommandsManager.new.set_commands!
# => { success: true, message: 'Commands set successfully' }

# Проверка текущих команд
Telegram::CommandsManager.new.current_commands
# => [{ command: 'start', description: '...' }, ...]
```

### Rake задача

```bash
# Установить команды
rake telegram:set_commands

# Показать найденные команды
rake telegram:set_commands DRY_RUN=true

# С указанием языка
rake telegram:set_commands LANGUAGE=ru
```

## Правила валидации

1. **Имя команды**
   - Только латинские буквы, цифры и подчеркивания
   - Длина от 1 до 32 символов
   - Строчные буквы

2. **Описание**
   - Длина от 1 до 256 символов
   - Не должно быть пустым

3. **Количество команд**
   - Максимум 100 команд для бота

## Обработка ошибок

1. **API ошибки**
   - Network timeout
   - Invalid token
   - Too many requests
   - Bad request

2. **Ошибки валидации**
   - Недопустимое имя команды
   - Слишком длинное описание
   - Дубликаты команд

3. **Ошибки парсинга**
   - Не удалось найти метод команды
   - Отсутствует описание в локали
