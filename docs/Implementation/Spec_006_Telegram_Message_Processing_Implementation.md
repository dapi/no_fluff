## Тестовые сценарии для реализации

### Сценарий 1: Базовое сохранение текстового сообщения из канала
```ruby
# Given: Webhook с текстовым сообщением из канала
# When: Обрабатываем webhook
# Then: Сообщение сохраняется в channel_messages, ответ не отправляется
```

### Сценарий 2: Проверка разных типов контента
```ruby
# Given: Webhook с фото/видео/документом из канала
# When: Обрабатываем webhook
# Then: Контент корректно сохраняется с правильным message_type
```

### Сценарий 3: Игнорирование канальных сообщений
```ruby
# Given: Webhook с сообщением из канала
# When: Обрабатываем webhook
# Then: Никакие методы ответа не вызываются
```

### Сценарий 4: Прямые сообщения работают как раньше
```ruby
# Given: Webhook с прямым сообщением пользователя
# When: Обрабатываем webhook
# Then: Сообщение обрабатывается стандартной логикой
```
