## Детальная имплементация по этапам

### Этап 1: Модели и бизнес-логика

#### TelegramUser методы
```ruby
def can_add_channel?
  is_premium || channels_count < ChannelService::FREE_CHANNELS_LIMIT
end

def channels_count
  subscriptions.count
end

def channels_limit_reached?
  !is_premium && channels_count >= ChannelService::FREE_CHANNELS_LIMIT
end
```

## Критерии успеха

1. ✅ Бесплатные пользователи могут добавить не более 10 каналов
2. ✅ Лимит учитывает все подписки (независимо от статуса активности)
3. ✅ Премиум пользователи могут добавлять неограниченное количество каналов
4. ✅ Система предлагает подписку при достижении лимита
5. ✅ Все существующие функциональности продолжают работать
6. ✅ Покрытие тестами > 90% для нового функционала
