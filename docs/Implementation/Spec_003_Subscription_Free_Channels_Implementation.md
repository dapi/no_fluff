class UpdateSubscriptionsDefaultActive < ActiveRecord::Migration[8.0]
  def change
    change_column_default :subscriptions, :active, from: false, to: true
    # Активировать существующие подписки
    Subscription.where(active: false).update_all(active: true)
  end
end
```

  def change
    change_column_default :channels, :active, from: false, to: true
    # Активировать существующие каналы
    Channel.where(active: false).update_all(active: true)
  end
end
```

#### TelegramUser методы
```ruby
def can_add_channel?
  is_premium || active_channels_count < ChannelService::FREE_CHANNELS_LIMIT
end

def active_channels_count
  subscriptions.active.count
end

def channels_limit_reached?
  !is_premium && active_channels_count >= ChannelService::FREE_CHANNELS_LIMIT
end
```

## Критерии успеха

1. ✅ Новые каналы автоматически активируются для мониторинга
2. ✅ Бесплатные пользователи могут добавить не более 10 каналов
3. ✅ Премиум пользователи могут добавлять неограниченное количество каналов
4. ✅ Система предлагает подписку при достижении лимита
5. ✅ Все существующие функциональности продолжают работать
6. ✅ Покрытие тестами > 90% для нового функционала
