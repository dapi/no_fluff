### Оптимизированный запрос для получения каналов

```ruby
Channel.left_joins(:subscriptions)
      .where(subscriptions: { active: true })
      .select(
        'channels.*',
        'COUNT(subscriptions.id) as active_subscribers_count'
      )
      .group('channels.id')
      .order('active_subscribers_count DESC')
```

### Форматирование одного канала

```ruby
def format_channel(channel, subscribers_count)
  status_icon = channel.active? ? '✅' : '❌'
  warning_icon = channel.last_post_at&.<(7.days.ago) ? '⚠️' : ''

  "#{status_icon} @#{channel.username} - 📊 #{subscribers_count} #{I18n.t('telegram_bot.channels.list.subscribers')} #{warning_icon}"
end
```

### Обработка пагинации

```ruby
def paginate_channels(channels, page = 1, per_page = 20)
  offset = (page - 1) * per_page
  total_pages = (channels.count.to_f / per_page).ceil

  {
    channels: channels.limit(per_page).offset(offset),
    current_page: page,
    total_pages: total_pages,
    total_count: channels.count
  }
end
```
