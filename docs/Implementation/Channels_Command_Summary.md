## 🎯 Функциональные возможности

### Основная команда
```
/channels
```
- **Доступ**: Только администраторы
- **Вывод**: Список всех каналов с информацией
- **Сортировка**: По количеству подписчиков (убывание)

### Формат вывода
```
📊 Список каналов в системе (всего: 6)

1. ✅ @popular_channel - 📊 3 подписчика
   📝 Very popular channel
   📅 Последний пост: 1 день назад

2. ✅ @medium_channel - 📊 3 подписчика
   📝 Medium popularity channel
   📅 Последний пост: 3 часа назад

3. ❌ @inactive_channel - 📊 1 подписчик
   📝 Inactive channel
   📅 Последний пост: 2 дня назад
```

### Индикаторы статуса
- ✅ Активный канал с недавними постами
- ⚠️ Активный канал, но посты старше 7 дней
- ❌ Неактивный канал

### Пагинация
- **На странице**: 20 каналов
- **Навигация**: Кнопки "← Предыдущая" и "Следующая →"
- **Информация**: "Страница X из Y"

### Навигационные команды
- `channels_page:N` - переход на страницу N
- `close_channels_list:` - закрытие списка
