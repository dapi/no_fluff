# Инструкция по управлению Follower Users

## Обзор

Follower Users - это специальные аккаунты для мониторинга Telegram-каналов. Администраторы могут управлять этими пользователями через специальные команды бота.

## Доступные команды

### 🔐 Административные команды

Только администраторы могут использовать следующие команды:

#### `/fadd <номер_телефона>`
Добавить нового follower пользователя.

**Пример:**
```
/fadd +79123456789
```

**Результат:**
- ✅ Успешно добавляет пользователя с нормализованным номером
- 📞 Запускает процесс авторизации через Telegram
- ❌ Ошибка если номер неверный или пользователь уже существует

#### `/fconfirm <номер_телефона> <код>`
Подтвердить авторизацию follower пользователя.

**Пример:**
```
/fconfirm +7 912 345-67-89 123456
```

**Результат:**
- ✅ Успешно подтверждает авторизацию пользователя
- ❌ Ошибка если код неверный или пользователь не найден

#### `/fremove <номер_телефона>`
Удалить follower пользователя.

**Пример:**
```
/fremove +7 912 345-67-89
```

**Результат:**
- ✅ Успешно удаляет пользователя из системы
- ❌ Ошибка если пользователь не найден

#### `/flist`
Показать список всех follower пользователей в системе.

**Пример:**
```
/flist
```

**Результат:**
- 📋 Показывает нумерованный список пользователей
- 📊 Отображает статус каждого пользователя
- 🔄 Показывает количество каналов на каждого пользователя

## Статусы пользователей

- ✅ **Авторизован** - пользователь успешно авторизован
- ⏳ **Ожидает авторизации** - ожидается ввод кода из Telegram
- ❌ **Ошибка авторизации** - ошибка в процессе авторизации
- 🚫 **Заблокирован** - пользователь заблокирован
- 🔄 **Авторизация отозвана** - авторизация была отозвана

## Форматы номеров телефонов

Система поддерживает различные форматы номеров:

- `+79123456789`
- `7 (912) 345-67-89`
- `89123456789`
- `+7 912 345-67-89`

Все номера автоматически нормализуются в международный формат.

## Примеры использования

### Полный цикл добавления пользователя

1. **Добавление пользователя:**
   ```
   /fadd +79123456789
   ```
   *Ответ: 📞 Авторизация пользователя с телефоном +7 912 345-67-89 начата. Введите код из Telegram.*

2. **Просмотр списка:**
   ```
   /flist
   ```
   *Ответ: 📋 Список Follower users:
   1. ⏳ +7 912 345-67-89 | Ожидает авторизации*

3. **Подтверждение авторизации:**
   ```
   /fconfirm +7 912 345-67-89 123456
   ```
   *Ответ: ✅ Пользователь с телефоном +7 912 345-67-89 успешно авторизован*

4. **Проверка статуса:**
   ```
   /flist
   ```
   *Ответ: 📋 Список Follower users:
   1. ✅ +7 912 345-67-89 | Авторизован*

## Обработка ошибок

### Неверный формат номера телефона
```
/fadd invalid_phone
```
*Ответ: ❌ Неверный формат номера телефона*

### Пользователь уже существует
```
/fadd +79123456789
```
*Ответ: ❌ Пользователь с телефоном +7 912 345-67-89 уже существует*

### Пользователь не найден
```
/fconfirm +79123456789 123456
```
*Ответ: ❌ Пользователь с телефоном +7 912 345-67-89 не найден*

### Неверный код подтверждения
```
/fconfirm +7 912 345-67-89 wrong_code
```
*Ответ: ❌ Неверный код подтверждения для пользователя с телефоном +7 912 345-67-89*

## Безопасность

- 🔒 Только администраторы могут использовать follower user команды
- 🛡️ Все команды требуют прав администратора (`is_admin: true`)
- 📝 Все действия логируются для аудита

## Интеграция с Telegram API

Система интегрирована с Telegram TDLib API через `AuthorizationService`:
- Автоматическая отправка кодов подтверждения
- Отслеживание статуса авторизации
- Безопасное хранение данных авторизации

## Мониторинг

Каждый follower пользователь может отслеживать до 100 каналов (в зависимости от тарифного плана).

## Поддержка

При возникновении проблем:
1. Проверьте правильность формата номера телефона
2. Убедитесь что у вас есть права администратора
3. Проверьте статус пользователя через `/flist`

Для технической поддержки обращайтесь к разработчикам системы.
