### Webhook для уведомлений
- URL: `https://your-domain.com/webhooks/ckassa`
- Метод: POST
- Формат: JSON

### Параметры для проверки подписи
- Секретный ключ: `CKASSA_SECRET_KEY`
- Параметры для проверки: *указать какие параметры используются*

### Обработка статусов платежа
- Успешная оплата: `success`
- Ошибка: `error`
- В обработке: `pending`
