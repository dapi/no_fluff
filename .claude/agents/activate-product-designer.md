# Активация агента "Продуктовый дизайнер"

## Когда использовать

Запустите этого агента когда вам нужна помощь с:

### UX/UI дизайном
- Проектирование пользовательского интерфейса бота
- Оптимизация пользовательского пути
- Создание онбординга для новых пользователей
- Дизайн диалоговых сценариев

### Исследованиями пользователей
- Анализ целевой аудитории и их потребностей
- Изучение болей и мотиваций пользователей
- Создание user personas и journey maps
- Анализ конкурентов и лучших практик

### Продуктовыми решениями
- Генерация гипотез по улучшению продукта
- Проектирование новых фич
- Оптимизация текущего функционала
- Работа с метриками и аналитикой

## Команды активации

### Полная активация
```
@product-designer
```
Активирует полного агента со всей экспертизой в продуктовом дизайне

### Контекстные команды
```
@product-designer [задача]
```
Примеры:
- `@product-designer спроектируй онбординг для новых пользователей`
- `@product-designer проанализируй UX текущего меню бота`
- `@product-designer создай user persona для нашего сегмента "Предприниматель"`
- `@product-designer предложи улучшение для процесса настройки фильтров`

### Быстрые запросы
```
UX-совет: [вопрос]
Дизайн-идея: [проблема]
Пользователь: [сценарий]
```

## Примеры использования

### Проектирование интерфейса
```
@product-designer

Нужно спроектировать интерфейс для настройки AI-фильтров в боте.
Пользователи должны легко:
1. Выбирать типы контента для фильтрации
2. Настраивать пороги важности
3. Добавлять исключения
4. Просматривать статистику

Сделай UX-анализ и предложи структуру меню.
```

### Анализ пользователей
```
@product-designer

Проанализируй нашего пользователя из сегмента "Продуктивный профессионал":
- IT-специалист, 25-45 лет
- 30-50 профессиональных каналов в подписке
- Готов платить за премиум
- Боль: нехватка времени

Создай detailed user persona и предложи 3 ключевые фичи для него.
```

### Улучшение онбординга
```
UX-совет: Как улучшить онбординг для бота, чтобы пользователи не бросали на первом шаге?

Текущий процесс:
1. Пользователь нажимает "Start"
2. Бот предлагает выбрать каналы для анализа
3. Пользователь должен вручную добавить 3+ канала
4. 50% отваливаются на шаге 3
```

## Интеграция с процессом

### TDD подход
Агент следует принципу Test-Driven Development:
1. Создает гипотезу/тест
2. Проектирует решение
3. Валидирует результат
4. Итерирует на основе данных

### Работа с командой
- **Разработчикам:** Детальные технические требования для дизайна
- **Менеджерам:** Обоснование решений через метрики и исследования
- **Пользователям:** Понятные интерфейсы и решения реальных проблем
